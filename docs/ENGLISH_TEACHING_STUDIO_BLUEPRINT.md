# 霧臺英語教學館（Wutai English Studio）改版藍圖 v1.0

> **規劃定稿日**：2026-11-23  
> **前身模組**：自然發音探索館（`?view=phonics`，同步支援 `?view=teaching`）  
> **核心定位**：專為國小英語教室互動大屏、教師 iPad 投影與學生回家預複習打造的「課堂互動白板與教具中心」

---

## 一、 全館共同架構與安全規範

1. **首頁入口與館名對齊**：
   - 繁中館名：**霧臺英語教學館**（七字對齊首頁各館）
   - 英文名稱：**Wutai English Studio**
   - 路由相容：保留 `?view=phonics` 與 `/phonics`，並同步支援 `?view=teaching` 別名。
2. **極簡單列頂欄與全屏白板殼 (`h-[100dvh]`)**：
   - 隱藏全站雙層 `<Header />`，將所有功能整併為極薄單列頂欄：
     `[ ← 首頁 ]  霧臺英語教學館  │  [ 🔤 拼音 ] [ 🃏 單字 ] [ 🧩 句型 ] [ ✍️ 板書 ]  │  [ ☀/🌙 ] [ 中/EN ] [ ⛶ ]`
3. **全館共用冊別／單元狀態**：
   - 共用一套「冊別／單元」進度選單（涵蓋 *Here We Go* 第 1～8 冊 40 個官方單元、教師專區、自由練習），切分頁免重選；並寫入 `sessionStorage`，從學生遊戲返回時還原原進度。
4. **三層國小安全字詞防護閘 (`src/services/profanityFilter.js`)**：
   - **第一層**：輸入與發音前即時檢查，含 Leetspeak（`0/1/3/4/5/7/@/$`）與重複字元正規化，以及安全白名單（避免誤殺 `class`、`grass`、`peacock`、`grapes`、`hello` 等課本正常詞）。
   - **第二層**：線上字典 API 回傳內容二次審查（含 `vulgar`、`offensive`、`derogatory`、`taboo`、`sexual` 等標籤直接阻擋）。
   - **第三層**：拼音白板重組整字時、發音前、自訂字卡新增、板書字帖輸入與 QR 學生暱稱全面套用。
5. **全館統一 🎮 遊戲手把連動**：
   - 單字、句型、板書分頁右上角統一提供 **`🎮`** 按鈕，將目前冊別單元帶入對應學生遊戲（單字館 / 句型積木工坊 / 神筆筆順書寫），目標頁左上角顯示 **`← 回霧臺英語教學館`**（旁附 `↗` 新分頁小鍵，不中斷課堂計分板與 QR 連線）。

## 二、 四大主分頁規格

### 1. 🔤 自然發音（雙子切換：`磁吸拼讀白板` ｜ `🎯 隨堂聽音小測`）
- **磁吸拼讀白板**：
  - 延續 135 個真人錄音檔與三層音訊引擎；取消手指滑動條，改採精準點唸（點音素唸音素 / 點連綴拼讀逐音合唸 / 點整字膠囊直唸整字）。
  - 預設中央 1 排，可按 `+/-` 增減至最多 4 排上下對齊（含 **`複製此排`** 一鍵複製對照如 `cat / cate`、拖曳疊放原地覆蓋替換、修正 `a_e` 分離母音拼字順序）。
  - 串接 *Here We Go* 第 1～8 冊 40 單元官方字母拼讀大綱（`ALL Contents.pdf`），自動高亮本課目標音組，並支援「✨ 載入本課對照範例」與「✍️ 送至板書」。
- **隨堂聽音小測**：
  - 依目前所選冊別單元自動抽出符合該課規則的短字題庫（刻意納入同單元易混淆音素為干擾選項）。
  - 支援 **`🔊 電腦發音`** 與 **`👩‍🏫 老師口唸（靜音出題）`** 雙模式切換。

### 2. 🃏 單字（三模式：`📖 單字教學` ｜ `🃏 抽考閃卡` ｜ `🔗 中英文連連看`）
- 串接雲端／課本單元單字、教師專區與現場自訂生字（含安全過濾）。
- **📖 單字教學**：逐字母打字機報讀拼字、音節分色切分、單字資訊卡（**預設國際音標 IPA＋一鍵對照 KK**、詞性、解釋、課本例句、同反義詞；1～8 冊內建離線精準辭典，課外字採安全過濾線上字典）＋ `✍️ 送至板書`。
- **🃏 抽考閃卡**：隨機中間出字（看中說英／看英說中／聽音猜字）＋ **實體拖拉手把滑動遮卡**（可半拉偷看提示）。
- **🔗 中英文連連看**：支援點選配對與拉線配對，配對成功即時朗讀。
- 附 **`🎮 去單字館`** 連動本單元單字遊戲。

### 3. 🧩 句型（五大模式 ＋ 📘 國小 10 大視覺化文法表）
- 串接第 1～8 冊 524 句句型庫（忠實依課本原字切塊，不額外拆解縮寫）。
- 支援：**教學展示（文法色塊開關＋單塊點唸＋常/慢速朗讀）**、**代換練習（點字塊變挖空槽替換本課單字）**、**白板重組（一鍵打亂＋可選干擾詞）**、**問答配對（Q&A 雙排＋單邊遮罩）**、**中翻英（手把遮片／逐塊揭曉）**。
- 內建 **三級長句自動縮放引擎 ＋ `A-/A+` 微調**（長句自然折行不破字、無橫向捲軸）。
- 內建 **`📘 本課文法表 & 國小 10 大視覺化文法總表`**（依單元自動對應、生活口訣＋色塊對照表＋例句點讀）。
- 附 **`🎮 去句型積木工坊`** 連動本單元。

### 4. ✍️ 板書（三模式：`🔤 大小寫筆順示範` ｜ `📝 看中文寫單字` ｜ `🖊️ 自由四線板書`）
- **🔤 大小寫筆順示範（一二年級）**：複用 26 大小寫四線三格筆順庫，動態動畫展示 ①②③ 筆畫順序與發音，支援直接疊描。
- **📝 看中文寫單字（三～六年級）**：左欄大字中文＋發音鈕，右欄寬敞四線三格畫布（支援單題大格／多列接力 3 題切換），按 **`👀 揭曉解答對照`** 直接在學生筆跡後方疊顯標準四線三格英文答案。
- **🖊️ 自由四線板書**：支援帶入本課單字／句型或自訂字詞作淺灰字帖底稿、開關底稿、開關四線格、1～3 行切換、白板／黑板綠切換、4 色筆＋粗細＋橡皮擦＋復原＋一鍵清空（橡皮擦永不擦掉四線底線）。
- 附 **`🎮 神筆筆順書寫`** 一鍵連動學生書寫遊戲。

## 三、 右側可收折課堂萬用工具列（霧臺特色）

- **單機即用工具**：
  1. **🦁 浮動分組記分板**：2～6 組霧臺神獸隊徽（雲豹／黑熊／山豬／水鹿／老鷹／貓頭鷹，可改名）、**縮小成懸浮條仍可直接點 `+1` 加分**、領先皇冠、全班加分、結算彩帶。
  2. **⏱️ 大字計時器**：倒數（常用秒數＋`±10s`＋視覺進度環＋最後 10 秒紅暈警示）與正計時碼錶，支援縮小角落持續運作。
  3. **🎲 立體 3D 骰子**：單骰（1–6）、雙骰（2–12）、英語朗讀風格指令骰（Loud / Whisper / Slow / Fast / Robot / Happy）。
  4. **✏️ 螢幕重點畫筆層 ＋ 🔊 課室音效 ＋ ⛶ 全螢幕**：預設關閉不干擾顯示器原生畫筆，需要時才開啟疊加標註。
- **📡 一鍵 QR Code 課堂連線室（Supabase Realtime 免建表）**：
  - 產生 4 碼代碼與大 QR Code，學生掃碼免建帳登入（已登入 6 碼通行證自動帶入姓名），共用：**班級抽籤（支援離線座號 1～N 與請假排除）**、**即時投票**、**全班搶答**。
